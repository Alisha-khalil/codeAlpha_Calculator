
# Calculator Web Application

A responsive and interactive calculator developed using HTML, CSS, and JavaScript to perform basic arithmetic operations through a clean and user-friendly interface.

## Project Links

- **Live Demo:**https://alisha-khalil.github.io/codeAlpha_Calculator/
- **Source Code:** [GitHub Repository](https://github.com/Sayyed-Alisha-Khalil/codeAlpha_Calculator)

## About the Project

The Calculator Web Application is a frontend development project created as part of the CodeAlpha Internship. It allows users to perform basic mathematical calculations with an interactive interface and real-time result preview.

## Features

- Addition, subtraction, multiplication, and division
- Real-time result preview
- Clear and delete functionality
- Decimal number support
- Basic error handling
- Division-by-zero handling
- Responsive design for different screen sizes
- Interactive button hover effects

## Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling and responsive design
- **JavaScript** – Calculator functionality and logic
